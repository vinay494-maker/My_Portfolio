# Vinay Kumar Madhugundu — Portfolio

This is a complete, self-contained copy of your portfolio website
(the same pages that are live at https://clean-display-canvas.lovable.app).

## What is inside

- `src/` — all the pages and styling
  - `src/lib/profile.ts` — **your words live here.** Name, bio, skills, projects,
    experience, education, contact details. Edit this one file to change text
    anywhere on the site.
  - `src/components/portfolio/` — the sections: top bar, hero, about, skills,
    projects, experience, education, resume, contact
  - `src/styles.css` — colours and fonts
- `public/vinay-portrait.jpeg` — your photo, shown in the top section of the site
- `public/vinaykumar_res.pdf` — your resume. Visitors get it saved as
  `Vinay_Kumar_Madhugundu_Resume.pdf` when they press any resume button.
- `public/favicon.svg` — the little VK icon shown in a browser tab

## Run it on your computer

You need [Bun](https://bun.sh) (or Node.js 20+). From this folder:

```text
bun install
bun run dev
```

Then open the web address it prints (usually http://localhost:8080).

## Make your own permanent copy

To turn this into a real website of your own, upload this folder to
[Netlify Drop](https://app.netlify.com/drop), Vercel, or GitHub Pages,
or keep using Lovable.

## Before you send this out

Fill in these three things in `src/lib/profile.ts` — they are still blank:

- `github` — your GitHub profile link
- `linkedin` — your LinkedIn profile link
- each project's `code` and `demo` links

Until then those buttons stay greyed out as "coming soon".
